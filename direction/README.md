# Focused homepage direction

Arabic: /direction/ar/ — English: /direction/en/

Prototype scope: hero, selected work, and inline contact form. About and Services navigate to the existing pages. Prototype pages are noindex. The form validates locally and never sends or stores personal data; CRM integration remains pending.

Design: Almond purple and lime, Alexandria typography, Aref Ruqaa Arabic accent, editorial imagery. The client PDF “مدن ملهمة بمشاركة سكانها” is reference only. No ministry branding, statistics, or proposed event details are presented as Almond credentials.

Hero photography: Thirdman, “Volunteers on Tree Planting,” Pexels.
Source: https://www.pexels.com/photo/volunteers-on-tree-planting-7656721/
License: https://www.pexels.com/license/
Used as illustrative community photography, not evidence of an Almond project or a Saudi location. Responsive WebP derivatives: 640, 1000 and 1600 pixels.

Portfolio imagery and project descriptions reuse the existing Almond portfolio content. No invented impact metrics.

Motion: restrained GSAP transforms, reversible scroll progress, reduced-motion support. Content remains visible without animation libraries. Form submission stays disabled without JavaScript.
